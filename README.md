Luxury Presence is the growth platform for residential real estate's top performers — real estate websites, AI CRM, SEO/GEO, paid ads management, AI lead nurture, collaborative search, and a branded client mobile app — serving 18,000+ agents, teams, and brokerages who have closed more than $450B in transaction volume. Its Public API (api.luxurypresence.com) is an API-key-secured REST CMS for managing agents, offices, teams, and their associated media, plus lead-activity webhooks signed with HMAC-SHA256. Documentation is hosted on a ReadMe developer hub that also exposes a hosted MCP server.

**Areas:** Company · Vertical Software · Real Estate · PropTech · CRM · Marketing · Websites · Webhook · Lead Generation
